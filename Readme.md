# Learning React ⚛️

This repository documents my journey of learning **React from scratch**.

I am starting with basic knowledge of **HTML, CSS, and JavaScript**, and gradually learning React by building small examples and projects along the way.

## 🎯 Goal

My goal is to understand React properly from the fundamentals rather than just following tutorials or copying code.

I will learn React step by step, practice what I learn, and document my progress every day.

## 📚 Learning Approach

Each day will have its own folder containing the React code and practice for that day.

All of my daily learning notes will be kept together inside a separate `readme` folder.

```text
learning-react/
│
├── day-1/
│   └── react-app/
│
├── day-2/
│   └── react-app/
│
├── day-3/
│   └── react-app/
│
├── readme/
│   ├── day-1.md
│   ├── day-2.md
│   ├── day-3.md
│   └── ...
│
└── README.md
```

Each daily README will contain:

- What I learned
- Concepts I understood
- What I practiced
- Problems I faced
- Things I need to improve
- What I plan to learn next
